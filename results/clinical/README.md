# Clinical analysis artifacts

Generated by `scripts/clinical_analysis.py` from 5-fold out-of-fold XGBoost risk for all 4,000 Set A patients. See [`docs/CLINICAL_ANALYSIS.md`](../../docs/CLINICAL_ANALYSIS.md) for the full report.

- `score_comparison.png`: ROC and decile calibration against the SAPS-I and SOFA scores supplied with the data.
- `decision_curve.png`: net benefit across alert thresholds.
- `funnel_plot.png`: standardised mortality ratio by ICU type with 95% and 99.8% control limits.
- `subgroup_performance.png`: AUROC (95% bootstrap CI) and observed/expected deaths by ICU type, age, sex, and ventilation.
- `gcs_recovery.png`: in-hospital mortality by GCS band at 0–12h and 36–48h, split by mechanical ventilation.
- `clinical_analysis.json`: every number in the report, without patient identifiers.
