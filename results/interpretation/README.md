# XGBoost interpretation artifacts

Generated by `scripts/explain_xgboost.py` from the selected 12h XGBoost model (seed 42, same patient split as the final benchmark) on the 400-patient sealed test split.

- `variable_importance.png`: mean |SHAP| per clinical variable, summed over that variable's window and summary columns.
- `shap_beeswarm.png`: per-patient SHAP values for the 15 strongest model columns; grey points are windows without a measurement.
- `risk_trajectories.png`: median and interquartile range of GCS, urine output, BUN, and heart rate in 6-hour bins for the highest- and lowest-risk test quartiles.
- `case_explanations.png`: variable contributions for the most confident correct alert, false alarm, and missed death at the validation threshold reaching 0.80 sensitivity.
- `interpretation.json`: the numbers behind the figures, without patient identifiers.
