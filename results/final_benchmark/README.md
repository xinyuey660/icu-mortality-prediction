# Final benchmark artifacts

This directory contains the reviewed report and figures from the completed five-model benchmark on all 4,000 labeled PhysioNet 2012 Set A records.

- `report.json`: configuration, model metrics, learned ensemble weights, bootstrap intervals, and limitations.
- `model_comparison.png`: comparison of test-set discrimination and calibration metrics.
- `calibration_curve.png`: observed versus predicted risk by probability bin.

Raw patient data, model checkpoints, and exploratory runs are intentionally excluded.
